# T9 — Restore yaml_val byte-identity and pin it

Found by T6 while writing the config-reading group.

T5's renderer carried a comment claiming its `yaml_val` was copied verbatim from `specclaw-build`.
It was not: the copy had dropped the two explanatory comments, swapped `echo "$value"` for
`printf '%s' "$value"`, collapsed the four quote-stripping lines onto two, and quoted one expansion.
`substitute()` — the other copied helper — *was* correctly byte-identical, so this was drift in one
helper, not a misunderstanding of the convention.

Restored the canonical body byte-for-byte from `specclaw-build`.

**The SC2295 wrinkle, and why it is resolved this way.** The canonical body contains
`value="${value%${BASH_REMATCH[0]}}"`, which shellcheck flags SC2295. That finding is **baselined
for all seven existing copies** (`specclaw-build`, `-pr`, `-gh-sync`, `-validate-change`,
`-discover-context`, `-azdo-pr`, `-jira-issue`) but a new file is not baselined, so the gate failed.
Three ways out, and only one is honest:

- Fix it in this copy alone → breaks the identity the convention exists to protect. No.
- Append the new file to `shellcheck-baseline.txt` → the repo forbids this by name. No.
- Fix all eight and prune seven baseline entries → a repo-wide refactor that does not belong in
  this change.

So: a targeted `# shellcheck disable=SC2295` with a written rationale, placed **above** the
definition, where it is outside the function body the identity test compares. The rationale names
the seven sibling copies and states that the expansion is a whitespace run matched by the regex
above it, so there is no pattern for the unquoted form to misinterpret.

Added **Group G** to the suite: `yaml_val` identity against `specclaw-build`, `substitute` identity
against the collector, plus a third assertion that both canonical extractions are non-empty — a
typo'd function name would otherwise make both sides empty and the comparison would pass by
matching nothing.

**The assertion was proved to work by injecting the exact drift it exists to catch** (swapping
`echo` back to `printf '%s'`): G1 fails, G2 and G3 still pass, suite exits non-zero. Restored after.
